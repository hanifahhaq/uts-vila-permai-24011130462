## Deskripsi Singkat
Aplikasi web pemesanan vila sederhana berbasis statis (*frontend-only* tanpa *back-end* dan basis data) yang dikembangkan untuk membantu Pak Hendra (pemilik usaha Vila Permai di Puncak, Bogor) mengelola reservasi tamu secara digital dan terstruktur.

## Daftar Fitur
* **Render Dinamis JavaScript:** Data unit vila dimuat dari array objek JavaScript menggunakan `createElement` dan `appendChild`.
* **Kalkulasi Total Otomatis:** Perhitungan durasi malam dan total biaya langsung tampil secara *real-time* sebelum tombol pesanan ditekan.
* **Validasi Input Bahasa Indonesia:** Validasi ketat untuk nama, tanggal check-in/check-out, serta batas jumlah tamu (1-10 orang).
* **Penyimpanan Lokal (localStorage):** Menyimpan nama tamu terakhir agar lebih mudah diakses pada kunjungan berikutnya.
* **Pencarian Vila:** Fitur filter pencarian unit berdasarkan nama atau fasilitas.
* **Desain Responsif:** Mendukung tampilan optimal di perangkat mobile, tablet, dan laptop dengan *breakpoint* CSS *media queries*.
